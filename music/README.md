# Musiques du jeu

Dépose ici des fichiers audio (`.mp3`, `.ogg`, `.wav`, `.m4a`, `.flac`, `.opus`, `.aac`).

À chaque push, le déploiement régénère `tracks.json`, et chaque morceau apparaît dans le menu « Musique » du jeu sous le nom du fichier, sans l'extension. Le premier morceau (par ordre alphabétique) est joué par défaut.

N'ajoute que des morceaux que tu as le droit de diffuser publiquement : ce dossier est servi sur GitHub Pages.
